# 常见问题

## Windsurf 发消息没有反应

检查顺序：

1. 程序左侧状态是否显示“代理运行中”。
2. Windsurf 补丁状态是否显示“已安装”。
3. 本地端口是否和补丁端口一致。
4. Windsurf 是否在安装补丁后重启过。
5. 日志里是否有 `GetChatMessage` 或上游错误。

## 测试连接失败

常见原因：

- API Key 错误或余额不足。
- 接口地址填错。
- 模型 ID 不存在。
- 接口类型选错，例如把 OpenAI Chat 接口选成 Anthropic。
- 中转站不支持当前思考参数。

如果错误里出现 `401`，优先检查 API Key。

如果错误里出现 `404`，优先检查接口地址和模型名。

如果错误里出现 `unsupported parameter`，可以把思考强度改为“默认（不指定）”。

## 上游返回 403

这通常不是程序本身的问题，而是上游拒绝请求。

例如：

- API Key 所属分组被删除。
- 当前 Key 没有模型权限。
- 中转站账户余额不足。
- 中转站限制了来源或请求类型。

## 如何知道 Windsurf 模型 ID

在 Windsurf 中切换模型并发送一次消息，然后点击程序中的“从日志发现模型”。

常见 BYOK 模型 ID 会内置在下拉框里，但 Windsurf 版本更新后可能新增或改名。

## 退出程序后代理还运行吗

当前版本逻辑：

- 选择“退出应用”：停止本程序启动的代理。
- 选择“最小化到托盘”：代理继续运行。

托盘图标在程序运行期间会保持显示。

## 如何恢复 Windsurf

点击“恢复补丁”，然后重启 Windsurf。

如果恢复失败，可以重新安装 Windsurf 或等待后续版本补充更完整的恢复工具。
